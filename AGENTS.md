# AGENTS.md

Guidance for AI coding agents working in `selfcare-login-frontend` (React 18 + TypeScript + Vite + MUI v5). See also `.github/copilot-instructions.md` for architecture and conventions.

## Setup (required before type-check or tests)

```bash
yarn install
yarn generate   # creates src/api/generated/selfcare-auth and openApi/generated-selfcare-auth (gitignored)
```

Without `yarn generate`, `tsc` and many tests fail with missing-module errors. Requires Node >= 24 and yarn 1.

## Commands

| Task | Command |
|---|---|
| Dev server | `yarn start` |
| Type-check | `yarn tsc --noEmit` |
| Lint | `yarn lint` (`yarn lint-autofix` to fix) |
| Format | `yarn prettify` |
| Unit tests | `yarn test` |
| Single test file | `yarn vitest run src/path/to/file.test.tsx` |
| Coverage | `yarn test:coverage` |

## Definition of done

1. `yarn tsc --noEmit` passes.
2. `yarn lint` passes with no new warnings.
3. Relevant tests pass (run targeted files, not the full suite, unless needed); add or update tests for changed behavior.
4. User-facing strings are added to **all** locale files in `src/locale` (`it`, `en`, `fr`, `de`, `sl`).

## Do not edit

- `src/api/generated/**`, `openApi/generated-*` – regenerated by `yarn generate`. To change generated output, edit `openApi/openapi.json`.
- `.env*` secrets, `coverage/`, `build/`, `node_modules/`.

## Gotchas

- This is the authentication entry point: never log or persist tokens/OTP/session data outside `src/utils/storage.ts`, and treat redirect/callback parameters as untrusted.
- `vitest.config.ts` uses the `forks` pool with `mockReset`, `restoreMocks` and `clearMocks` on; `*.spec.ts` and `e2e/**` are excluded from Vitest.
- `src/setupTests.ts` initializes i18n with the Italian locale only; tests assert on Italian text.
- Routing uses React Router v5; do not use v6 APIs.
- Prettier: 100 cols, single quotes, semicolons, trailing commas `es5`.
